# Outcome-blind publication-text thematic analysis

The FAIRification thematic stage uses the Dimensions-recovered publication anchor only. The input representation is title twice plus available abstract. It compares NMF solutions at K=2, K=3, and K=4 under fixed TF-IDF preprocessing and bootstrap stability diagnostics.

The model may not read or use grant, policy-document, citation, funder, organization, country, affiliation, or linkage variables. Theme labels remain provisional until a documented human review of terms, representative publications, assignment uncertainty, bootstrap stability, and sensitivity checks.

NMF outputs—including corpus text, terms, assignments, review packets, and diagnostics—are private data-derived materials and are not tracked here.

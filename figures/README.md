# Reviewed aggregate-only figures

`figures/manuscript/` contains five reviewed figures generated from the certified aggregate-only results bundle, in PNG and PDF formats. The accompanying `figure_captions.md` records the release-reviewed captions. These figure assets may be used in manuscript preparation, but the manuscript source itself is not hosted in this repository.

The figures display only aggregate results. They must be interpreted as evidence about Dimensions-recorded identifier links, descriptive stored record years, and a year-stratified configuration test. They do not demonstrate funding intent, causal funding effects, policy uptake, endorsement, impact, or institutional influence.

No raw source, Dimensions, publication-level, grant-level, policy-document-level, organization-level, issuer-level, or edge-level graphics are released.

# Derived outputs

This directory may contain reviewed, non-record-level analytical aggregates that are safe for repository release. The current `thematic/` subdirectory contains component-level NMF diagnostics and a topic cross-tab; its own README documents the permitted files and exclusion boundary.

Do not commit source data, raw Dimensions responses, record-level matching results, publication assignments, titles, abstracts, IDs, DOI tables, organization/funder/policy-document records, relation edges, serialized objects, or unreviewed outputs. Keep these materials in a protected local workspace outside Git-tracked paths.

# Dimensions relational retrieval contract

This note documents the local post-NMF retrieval implemented in `code/relational/07_retrieve_linkage_ready_publication_anchor.py`. It is a targeted enrichment of the frozen 144-record Dimensions publication set, identified exclusively by its already accepted Dimensions publication IDs. It does not redefine the source cohort or rerun the FAIRification search.

The request is deliberately limited to the publication identifier, `times_cited`, `supporting_grant_ids`, `authors`, `research_orgs`, `research_org_countries`, `research_org_names`, and `research_org_types`. Dimensions documents `supporting_grant_ids` as the list of Dimensions grant IDs linked to a publication. Its cross-source data model specifies that publication-to-grant relations are retrieved first as `supporting_grant_ids`, then the corresponding grant records are retrieved in a separate request. The API documentation describes `authors` as an ordered JSON list containing author names and original affiliations, with researcher and organization identifiers where available. It documents `research_orgs` as GRID organizations associated with a publication and notes that they are extracted from author-affiliation text and can be missing. `research_org_countries` identifies the countries of those affiliated organizations. [Dimensions publications schema](https://docs.dimensions.ai/dsl/datasource-publications.html) [Dimensions cross-source data model](https://docs.dimensions.ai/dsl/data-model.html)

The script does not request grant records, policy-document records, policy-document text, or policy issuers. Those are separate, subsequent retrievals. Returned `supporting_grant_ids` are database-recorded linkage identifiers only. They are not treated as proof of funding causation, funding influence, or any other causal relationship.

The publication title, abstract, year, date, and document-type fields carried into `publication_anchor_final` are copied from the pre-NMF text-metadata retrieval. This prevents a later API retrieval from changing the text corpus on which the frozen NMF themes were fitted. The script cross-checks that every K=3 assignment ID, title, year, and abstract-availability indicator agrees with that frozen text metadata before any post-NMF relational field is retrieved.

All raw requests, JSON responses, returned anchor records, and run manifests are local licensed materials. They must remain excluded from GitHub under the repository data boundary.
